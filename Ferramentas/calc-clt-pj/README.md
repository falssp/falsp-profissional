# Calculadora CLT vs PJ

Calculadora financeira interativa para comparação de regimes de contratação.

## Acesso

[https://falssp.github.io/falsp-profissional/Ferramentas/calc-clt-pj/](https://falssp.github.io/falsp-profissional/Ferramentas/calc-clt-pj/)

## O que é

Calcula e compara o custo/benefício real entre CLT e PJ, considerando:

- **CLT**: bruto → líquido (INSS e IRRF progressivos 2025), 13º, férias + ⅓, FGTS, PLR, VA/VR, home office, plano de saúde
- **PJ**: todos os regimes tributários (MEI, Simples Anexo III, Simples Anexo V, Lucro Presumido, Autônomo/RPA, alíquota customizada), despesas mensais, INSS próprio, provisão FGTS, férias por oportunidade
- **Break-even**: nota fiscal mínima para igualar o pacote CLT

## Uso

Arquivo HTML standalone — abre direto no browser, sem dependências externas além de Google Fonts.
